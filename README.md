# qwerty

공인중개사 1인용 매물 관리 대시보드. 엑셀/카톡으로 흩어져 있던 매물을 한 곳에서 검색·관리한다.

- **현재 상태**: MVP 목업. `index.html` 파일 하나를 브라우저로 열면 바로 동작
- **저장 위치**: 매물·사진·일정·메모는 열어본 기기의 같은 브라우저(IndexedDB)에 저장되어 새로고침 후에도 유지됨. 메모는 DB 저장 전 새로고침에도 마지막 입력을 복구할 수 있도록 임시 저장함.
- **저장 범위**: 다른 기기·브라우저와 공유되지 않음. 브라우저 사이트 데이터를 지우면 삭제됨. 로컬 파일과 배포 주소의 저장 공간도 서로 다름.
- **저장소**: https://github.com/sypyun-a11y/qwerty

## 브랜드

- **이름**: qwerty (소문자)
- **심볼**: 흰 집 실루엣 안에 열쇠 모양 q를 검정으로 뚫은 형태
- **컬러**: 밤 모드는 블랙 배경(#0A0A0A) + 밝은 글씨, 낮 모드는 화이트 배경 + 검은 글씨. 상단 밤/낮 버튼으로 전환하며 선택은 유지됨.
- **일정 태그**: 계약(보라), 입주(초록), 매물소개(파랑), 퇴실(빨강)
- **폰트**: 로고/숫자 IBM Plex Mono, 본문 IBM Plex Sans KR

## 기능

### 1. 매물 관리 탭

- **검색**: 띄어쓴 단어가 모두 들어간 매물만 표시 (예: `마포구 2룸`, `신공덕 테라스`, `양타`, 전화번호 뒷자리)
- **보기 3종**: 카드(사진 그리드) / 건물별(호실 표) / 장부(전체 표)
- **요약**: 종류별 개수, 퇴실 30일 이내 건수 → 누르면 필터
- **필터·정렬**: 타입, 상태 / 퇴실 임박순, 최근 등록순, 금액순
- **상세 패널**: 사진 갤러리, 전체 정보, 연락처 복사, 같은 건물 다른 호실, 호실 추가
- **빈 양식 복사**: 매물 목록 및 등록 화면에서 항목만 있는 빈 양식을 복사
- **빈 양식 넣기**: 등록 화면 입력칸에 양식을 넣고 작성 후 채우기로 자동 반영
- **양식 복사**: 상세 화면에서 등록된 매물 정보를 카톡 양식으로 복사
- **공시지가 표시**: `2억 5,086만원 (250,861,968원)`처럼 읽기 쉬운 금액을 먼저 표시
- **사진**: 여러 장 업로드, 첫 장이 대표 사진 (자동 압축)

### 2. 캘린더 탭

- 매물의 **퇴실가능일**(빨강)과 **만기일**(노랑)이 자동으로 표시
- 날짜 클릭 → 일정 추가/삭제 (시간, 메모)
- 등록 시 계약·입주·매물소개·퇴실 태그를 선택. 캘린더와 일정 상세에 각각 다른 색으로 표시

### 3. 메모장 탭

- 첫 줄이 제목, 입력하면 자동 저장
- 상단 고정, 검색

## 매물 등록 양식

등록 화면의 **"카톡 양식 붙여넣기"** 칸에 아래 형식 그대로 붙여넣고 **채우기**를 누르면 항목이 자동으로 채워진다. 상세 화면의 **양식 복사**도 같은 형식으로 나온다.

```
주소:
신축/구축:
종류(전세,월세,매매,상가,사무실):
금액:
관리비:
타입(1룸,1.5룸,2룸,3룸):
공시지가 126%:
퇴실가능일:
만기일:
보증보험 가능여부:
주택임대사업자 가입여부:
임대인 번호:
임차인 번호:
수수료:
특이사항:
```

| 항목 | 입력 방식 | 비고 |
|---|---|---|
| 주소 | 주소 / 건물명 / 호수 3칸 | 붙여넣기 시 자동 분리 |
| 신축/구축 | 선택 | |
| 종류 | 전세·월세·매매·상가·사무실 | 월세·상가·사무실은 월세 칸 추가 |
| 금액 | 보증금(만원) / 월세(만원) | `2억 1,000` 형식도 인식 |
| 관리비 | 원 | |
| 타입 | 1룸·1.5룸·2룸·3룸·기타 | 실면적(평), 테라스·복층·높은층고 추가 가능 |
| 공시지가 126% | 원 | 보증금이 126% 이내인지 자동 계산 (참고용) |
| 퇴실가능일 | 날짜 ("이후") | 캘린더·D-day 연동 |
| 만기일 | 날짜 | 캘린더 연동 |
| 보증보험 가능여부 | 가능·불가·확인필요 | |
| 주택임대사업자 가입여부 | 주택임대사업자·일반임대인·확인필요 | |
| 임대인/임차인 번호 | 전화번호 | 자동 하이픈 |
| 수수료 | 자유 입력 | 양타·단타 버튼 |
| 상태 | 광고중·계약진행·계약완료 | |
| 특이사항 | 자유 입력 | 여러 줄 가능 |

**주의할 점**

- 날짜에 연도가 없으면 올해로 넣고, 넉 달 넘게 지난 날짜면 내년으로 넣음 → 등록 전 확인
- 126% 판단은 보증금과 공시지가 126%만 비교한 참고치. 실제 보증보험 가능 여부는 선순위 채권 등까지 따로 확인 필요
